# 영상 근거: 라벨 확인과 실패 유형

## 영상을 어떻게 썼나

과제 공지는 성공·실패를 **영상 없이 CSV 로그로** 판단하라고 합니다. 그래서 영상은 모델 입력에 쓰지 않고, 아래 확인과 설명에만 썼습니다.

- 라벨 확인: 마지막 장면에서 병이 상자 안에 서 있는지 확인
- 실패 유형 분류: 손을 펴는 순간 전후 장면으로 왜 넘어졌는지 확인
- 군집 이름의 근거와 보고서 그림

예외가 하나 있습니다. 영상에서 본 실패 순간(B형)에 맞춰 로그 특징 `thumb_open_02s`를 하나 정했습니다. 이 특징 자체는 CSV에서만 계산하지만 영상을 보고 고른 것이라, 사용 범위는 교수님·TA에게 확인하는 것을 권장합니다([5차 실험 보고서](../fifth_model/README.md)).

## 영상과 로그의 정렬

- 1차 데이터 영상 48개: 왼쪽 시점(`observation.images.left_view`), 640×360, 30fps
- 48개 모두 영상 프레임 수가 CSV 줄 수와 같습니다([alignment.csv](alignment.csv)).
- 따라서 CSV i번째 줄이 영상 i번째 프레임입니다. 로그로 찾은 "손가락이 펴지기 시작한 프레임"(`src.phases.segment`의 `open_start`) 장면을 바로 볼 수 있습니다.

## 라벨 확인: 48/48 일치

마지막 장면 기준으로 성공 27개는 모두 병이 상자 안에 서 있고, 실패 21개는 모두 누워 있거나(19개) 왼쪽 벽에 기대 있습니다(2개: 21, 45번). 경계 사례는 다음과 같습니다.

| 에피소드 | 라벨 | 메모 |
|---|---|---|
| 23 | 성공 | 높은 곳에서 놓았지만 똑바로 떨어져 섰음 (운이 좋은 경우) |
| 41 | 성공 | 놓은 뒤 흔들리다 상자 앞쪽 왼쪽 모서리에 붙어 섰음 |
| 21, 45 | 실패 | 넘어지지 않고 벽에 기울어진 채 끝남 |

## 실패 유형

손가락이 펴지기 시작한 순간부터 0.1초 간격으로 장면을 보고 나눴습니다. 표 전체는 [video_annotations.csv](video_annotations.csv)에 있습니다.

| 유형 | 개수 | 에피소드 | 무슨 일이 있었나 |
|---|---:|---|---|
| A. 높은 곳에서·기울여 놓음 | 14 | 1, 3, 4, 5, 6, 7, 8, 10, 11, 12, 13, 15, 18, 28 | 병 바닥이 상자 바닥에 닿기 전에, 또는 기울어진 채 손을 폄 → 0.3초 안에 넘어짐 (10, 13번은 잠시 섰다가 넘어짐) |
| B. 세웠지만 손을 펴며 넘어뜨림 | 7 | 19, 21, 25, 35, 44, 45, 48 | 병은 바닥에 섰는데 손이 펴지고 빠지는 0.1~0.3초 사이에 손가락이 윗부분을 밀거나(넘어짐) 끌어당김(21, 45번: 벽에 기댐) |

- A형은 1~28번, B형은 19~48번에 있습니다. 조작이 익숙해지며 높게 놓는 실수는 사라졌고, 남은 실패는 놓는 순간의 손동작에서 나왔습니다.
- 3, 13, 28번은 유형 판단의 확신이 중간입니다.

### 영상에서 잰 놓는 높이

손을 펴기 시작한 프레임에서, 상자 왼쪽 위 영역의 가장 위쪽 어두운 픽셀(병뚜껑 또는 장갑)이 상자 뒤쪽 테두리보다 몇 픽셀 위에 있는지 쟀습니다. 상자 뒤쪽 테두리의 화면 위치는 48개 영상 모두 같았습니다(좌우 위치만 몇 픽셀 차이).

| 그룹 | 평균 (픽셀) |
|---|---:|
| 성공 | 18.8 |
| A형 실패 | 35.8 |
| B형 실패 | 7.6 |

- 25픽셀 이상에서 놓은 20개의 성공률은 35%, 그보다 낮게 놓은 28개는 71%입니다.
- B형은 오히려 성공보다 낮게 놓았습니다. 높이로는 설명되지 않는 실패입니다.

## 다시 만들기

영상은 레포에 없습니다. 영상 폴더를 지정하면 정렬 확인표와 그림을 다시 만듭니다. OpenCV는 이 스크립트에만 필요합니다.

```powershell
.\.venv\Scripts\python.exe -m pip install opencv-python-headless
.\.venv\Scripts\python.exe -m experiments.video_evidence --video-dir <episode_000001.mp4 등이 있는 폴더>
```

라벨 확인과 실패 유형(`video_annotations.csv`)은 장면을 사람이 보고 판단한 결과이고, 놓는 높이는 자동으로 측정한 값입니다.
