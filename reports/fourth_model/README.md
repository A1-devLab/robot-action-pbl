# 4차 실험: 품질 점수를 분류기로 사용

## 목적

3차 모델(단계 특징 10개 + 로지스틱 회귀)의 반복 교차검증 정확도는 0.667, ROC AUC는 0.721입니다. 과제 4의 품질 점수가 성공·실패를 더 잘 정렬하므로, 점수 자체를 분류 규칙으로 쓰면 나아지는지 확인했습니다. 같은 조건에서 더 복잡한 모델(궤적 전체, ROCKET)이 의미 있는 개선을 주는지도 함께 비교했습니다.

## 분류 규칙

```text
score >= 50  →  성공,   score < 50  →  실패
```

- `score`는 [src/score.py](../../src/score.py)와 같은 공식입니다. 입력 4개(`delta_hold_l_sh_r`, `delta_hold_l_el_p`, `rev_elp_hold`, `t_retract`)를 같은 가중치로 평균하고, 기준 통계는 `reports/score/params.json`에 고정되어 있습니다.
- 50점은 기준 데이터 48개의 평균입니다. 임계값은 데이터로 학습하지 않습니다.
- 손이 한 번도 닫히지 않은 에피소드는 0점이므로 실패로 판정합니다.
- 구현: [src/classify.py](../../src/classify.py). 데모 출력에서는 하위 점수(`sub_carry`, `sub_smooth`, `sub_exit`)가 판정 이유를 함께 보여줍니다.

## 검증 방식

| 방식 | 내용 | 확인하려는 것 |
|---|---|---|
| A. 반복 교차검증 | `StratifiedKFold(5, shuffle=True)` × 시드 0~9, 정확도·균형 정확도·AUC의 평균 | 일반적인 교차검증 성능과 분할에 따른 변동 |
| B. 녹화 블록 | 에피소드 번호순으로 8개씩 6블록, 한 블록씩 빼고 학습 | 다른 시기에 녹화된 에피소드에서도 작동하는지 |

뒤로 갈수록 성공률이 오릅니다(1~16번 25%, 17~32번 69%, 33~48번 75%). 그래서 A만으로는 녹화 시기 차이를 학습한 모델도 좋아 보일 수 있어 B를 함께 봅니다.

라벨을 보는 모든 단계(입력 선택, 방향, 가중치, 임계값)는 학습 fold에서만 수행합니다. 4차 모델은 PR #4와 같은 규칙으로 매 학습 fold에서 입력 4개를 다시 고릅니다.

- 후보: 단계 특징 10개 + `t_reach`, `t_hold`, `t_retract` (군집 입력과 같은 13개)
- 규칙: 단일 특징 AUC가 0.5에서 먼 순서로 고르고, 이미 고른 입력과 |r| ≥ 0.9이면 건너뜀

"PR #4 입력 고정" 행은 48개 전체로 고른 입력을 그대로 쓰므로 낙관적인 참고값입니다.

## 결과

원본: [comparison.json](comparison.json), 에피소드별 결과: [oof_predictions.csv](oof_predictions.csv)

| 모델 | A 정확도 | A 균형 정확도 | A AUC | B 정확도 | B AUC |
|---|---:|---:|---:|---:|---:|
| 3차: 단계 특징 10개 + LogReg C=1 | 0.667 ± 0.035 | 0.657 | 0.721 | 0.688 | 0.695 |
| 단계 특징 10개 + LogReg C=0.1 | 0.690 ± 0.032 | 0.672 | 0.740 | 0.708 | 0.720 |
| **4차: 점수 ≥ 50, 입력을 학습 fold에서 다시 선택** | **0.696 ± 0.043** | **0.689** | **0.810** | **0.708** | **0.787** |
| 점수 ≥ 50, PR #4 입력 고정 (낙관적) | 0.715 ± 0.019 | 0.710 | 0.846 | 0.729 | 0.848 |
| 점수, 임계값을 학습 fold에서 튜닝 | 0.746 ± 0.040 | 0.757 | 0.810 | 0.667 | 0.787 |
| 궤적 8×40 + LogReg C=0.1 | 0.719 ± 0.039 | 0.706 | 0.754 | 0.729 | 0.772 |
| ROCKET 2,000 커널 + 릿지 | 0.650 ± 0.039 | 0.627 | 0.662 | 0.563 | 0.571 |

- 다수 클래스 기준 정확도는 0.5625입니다.
- 48개에서 정확도의 표준오차는 약 0.066(정확도 0.7 기준)입니다. 정확도 0.03~0.05 차이는 구분하기 어렵습니다.
- 궤적 8×40: 왼팔 7개 관절 + 엄지 pitch를 정규화 시간 40개 지점으로 보간했습니다.
- ROCKET(Dempster et al., 2020): 랜덤 팽창 합성곱 커널의 출력 요약을 특징으로 쓰는 시계열 분류 방법입니다.

학습 fold 50개에서 입력이 선택된 비율은 다음과 같습니다.

| 입력 | 비율 |
|---|---:|
| `delta_hold_l_sh_r` | 100% |
| `delta_hold_l_el_p` | 94% |
| `rev_elp_hold` | 86% |
| `t_retract` | 78% |
| `pose_grasp_l_sh_r` | 24% |
| `pose_release_l_el_p` | 12% |
| `t_reach`, `t_hold` | 4%, 2% |

PR #4와 같은 4개 조합은 62%의 fold에서 선택됐습니다.

## 해석

1. **정확도 개선은 작고, 분명한 개선은 순위입니다.** 4차 모델의 정확도는 3차보다 0.03 높아 표준오차 안입니다. AUC는 0.72에서 0.81로, 녹화 블록 검증에서는 0.70에서 0.79로 두 방식 모두에서 올랐습니다.
2. **분류와 품질 점수가 같은 공식이 됩니다.** 실패로 판정된 이유를 하위 점수로 바로 설명할 수 있어, 데모와 보고서에서 근거를 일관되게 제시할 수 있습니다.
3. **임계값은 고정합니다.** 학습 fold에서 튜닝하면 A 정확도는 0.746이지만 B에서는 0.667로 떨어졌습니다. 녹화 시기가 다른 데이터에서는 튜닝한 임계값이 오히려 불리했습니다.
4. **더 복잡한 모델은 이득이 없었습니다.**
   - 궤적 LogReg는 정확도가 비슷하지만(0.719) AUC가 낮고(0.754), 판정 이유를 설명하기 어렵습니다.
   - ROCKET은 B에서 기준선 수준(0.563)입니다. 특징 4,000개를 48개로 학습하면 녹화 시기 차이 같은 우연한 패턴을 먼저 학습하는 것으로 보입니다.
5. **대부분의 모델이 계속 틀리는 실패가 있습니다.** 에피소드 10, 21, 25, 28, 35, 44, 48은 7개 모델 중 과반이 시드의 80% 이상에서 성공으로 예측합니다. 현재 관절 특징으로는 성공과 구분되는 흔적이 약한 사례이며, 모델을 바꾸기보다 새 정보(예: 기구학으로 계산한 놓는 순간의 손 높이·기울기)가 필요합니다.

## 한계

- `t_retract`는 병을 놓은 뒤 팔이 돌아오는 시간입니다. 넘어짐의 원인이라기보다 결과에 대한 반응이거나 숙련도 신호일 수 있습니다. 1~16번, 17~32번에서는 성공·실패를 거의 구분하지 못하고(단일 AUC 0.48), 33~48번에서만 강하게 작동합니다(0.94).
- 점수와 에피소드 번호의 순위 상관이 0.72로 높습니다(PR #4 보고). 녹화 블록 검증으로 일부 확인했지만, 다른 날 녹화한 데이터에서의 성능은 아직 확인하지 못했습니다.
- 데이터는 48개 한 세트뿐입니다. 추가 데이터가 제공되면 학습에 넣기 전에 먼저 이 규칙의 검증용으로 쓰는 것을 권장합니다.
