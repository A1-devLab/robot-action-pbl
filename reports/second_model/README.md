# 2차 실험: 왼팔 state 특징 선택

## 변경점

1차의 208개 전체 state/action 통계 대신 왼팔 7개 관절의 state만 사용한다. 각 관절의 평균, 표준편차, 범위, 끝-시작 차이를 포함해 28개 특징이다. 로지스틱 회귀의 L2 규제(C=1), 0.5 임계값과 1차 결과의 에피소드 단위 5개 fold 배정을 유지했다. 표준화는 각 학습 fold에서만 계산했다.

## scikit-learn 1.9.1 실행 결과

| 구성 | 정확도 | 균형 정확도 | 혼동행렬 (실패/성공 순) |
| --- | ---: | ---: | --- |
| 1차: 전체 특징 208개 | 27/48 = 56.25% | 54.23% | [[8, 13], [8, 19]] |
| 2차: 왼팔 state 특징 28개 | 31/48 = 64.58% | 63.76% | [[12, 9], [8, 19]] |

2차는 실패 21개 중 12개, 성공 27개 중 19개를 맞혔다. 1차보다 실패 4개를 더 맞혔고, 전체 정답도 4개 늘었다. 기존 `src.train.evaluate`를 그대로 사용해 1차 56.25%도 재현했다. `sklearn_comparison.json`과 `sklearn_oof_predictions.csv`에 실제 실행 결과를 기록했다.

## 재현 및 해석 주의

`experiments/second_model_sklearn.py`를 실행한다. 앞서 패키지 설치가 차단됐을 때 사용한 `experiments/second_model.py`와 `comparison.json`은 표준 라이브러리 재구현의 탐색 결과이며, scikit-learn 결과의 근거로 사용하지 않는다. 재구현은 1차에서 경계 사례 하나를 다르게 예측했다.

48개 사례 중 한 건은 정확도 2.08%p다. 한 번의 5겹 분할에서 후보를 반복 선택하면 낙관적인 결과가 되므로, 최종 후보는 다른 시드의 반복 교차검증이나 별도 테스트로 검증한다. 이번 데이터에서 나타난 성능 향상이 새로운 데이터에서도 유지되는지는 아직 확인되지 않았다.

실행: `python -m experiments.second_model_sklearn` (리포 루트에서, `requirements.txt` 설치 후).
